## 0. 전달받은 철학 — 홈이 말해야 하는 네 문장

대표가 준 카피를 압축하면 홈의 서사는 네 개다. 지금 홈은 1·4는 갖췄지만 2·3이 약하다.

| # | 철학 | 현재 홈 상태 |
|---|---|---|
| P1 | **분산 발주의 종말** — "파워링크는 광고대행사에게, 블로그는 블로그 대행사에게… 맡기고 있습니까?" | ✅ ProblemSection 수렴 인터랙션이 이미 표현. 카피만 질문형으로 교체 |
| P2 | **하나의 계약** — 6개 영역 전체 품목이 한 계약 안에 (PAID / SEARCH / AI SEARCH / CONTENT / WEBSITE / CONVERSION) | ❌ ChannelGrid 는 5개 카드 나열. CONVERSION 이 별도 섹션이라 "전체가 하나"로 안 읽힘. 세부 품목(Meta Ads, 숏폼, 사건별 CPA…)이 화면에 없음 |
| P3 | **변해도 조항** — "네이버가 변해도. Google이 변해도. AI가 새 접점이 되어도. 우리가 먼저 대응한다" + ChatGPT Ads 즉시 편입 | ⚠️ FutureReady 가 존재하나 선언의 리듬과 구체 근거(ChatGPT Ads 한국 파일럿)가 없음 |
| P4 | **전 과정 소유** — "우리가 관리하는 것은 광고가 아니다. 발견→검색→비교→신뢰→상담→수임 전체다" | ✅ MarketingSystem 6단계가 표현. 도입 선언문만 추가 |

**사실 검증(§42):** "ChatGPT Ads 한국 서비스 시작" — 사실. OpenAI 는 2026-06-19 한국에서
광고 파일럿을 시작했다(무료·Go 플랜 노출, Plus 이상 제외). 단 법률서비스 카테고리 허용
여부는 확인되지 않았으므로 카피의 "허용 범위가 확대될 경우 즉시 편입" 조건부 표현을
그대로 유지한다. 출처: openai.com/index/testing-ads-in-chatgpt, koreatimes.co.kr(2026-06-19).

## 1. 디자인 방향 — 계약서 에디토리얼

**콘셉트 한 줄: 홈페이지 자체가 '하나의 계약서'처럼 읽힌다.**

철학의 중심 단어가 "하나의 계약"이므로, 시각 언어를 법률 문서에서 가져온다.
로펌 대표는 매일 계약서를 읽는 사람이다 — 조항 번호, 별지 목록, 서명란은
그들에게 가장 익숙한 신뢰의 형식이다. 이것이 이 사이트를 기억하게 만드는
한 가지(unforgettable thing)다.

- 섹션 = **조(條)**. "제1조 — 문제", "제2조 — 계약 범위"처럼 번호가 실제 구조를 가리킨다
  (장식 넘버링 금지 원칙에 부합 — 계약서에서 조 번호는 정보다).
- 서비스 품목 = **별지(부속서) 표**. 카드 그리드가 아니라 계약 별지처럼 품목을 전부 나열한다.
- 채널 현황 = **레저(ledger)**. 운영 중 / 조건부 대기(승인 시 편입)를 회계 장부처럼 기록.
- 마지막 CTA = **서명란**. "로펌은 사건에 집중하십시오" 선언 아래 서명선과 진단 요청 버튼.

### 스킬 분석 근거

`ui-ux-pro-max` (--design-system "law firm marketing agency b2b professional trust editorial"):
- 스타일 매칭: **Trust & Authority** — credentials 명시, 수치 있는 사례, WCAG AAA.
  안티패턴: generic content · no credentials · AI purple/pink gradients.
- 컬러 DB(B2B Service/Consulting Firm): Navy `#0F172A` + Blue CTA `#0369A1` + `#F8FAFC` 바탕
  → 현행 리뉴얼 토큰(잉크 `#0E1116` / 오프화이트 `#FBFAF8` / 브랜드 블루)과 동일 계열.
  **팔레트는 교체하지 않고 유지**한다. 이미 스킬 권고와 일치하고, 브랜드 연속성(§5.1)이 우선.
- 타이포 무드(법률): **세리프 권위**(EB Garamond 계열) — 국문에는 세리프 디스플레이로 번역.
- 스타일 DB: **Exaggerated Minimalism** — 오버사이즈 타이포 + 대비 + 여백, 에디토리얼/에이전시에 적합,
  Complexity Low·성능 우수 → 선언문 무대의 기법으로 채택.

`frontend-design`:
- "Inter 같은 제네릭 폰트 회피" → 현행 영문 라벨 Inter 를 교체한다.
- "볼드는 한 곳에, 주변은 조용히" → 볼드는 '계약서 모티프 + 오버사이즈 선언문'에만 쓰고
  나머지는 현행 절제 유지.
- "하나의 잘 짜인 등장이 흩어진 마이크로 인터랙션보다 낫다" → 강한 연출 3개 상한(§18) 유지.

### 타이포그래피 델타

| 역할 | 현행 | 개편 | 이유 |
|---|---|---|---|
| 국문 본문 | Pretendard | **유지** | 가독성·서브셋 최적화 완료 |
| 국문 선언문/H1 | Pretendard 700 | **Noto Serif KR 600~700** (신규 `--mt-serif`) | 법률 문서의 세리프 권위. 판결문·계약서의 명조 감각 |
| 영문 라벨/숫자 | Inter | **IBM Plex Mono 500** | 계약서 타자기·장부 무드 + frontend-design 의 Inter 회피 지침. tabular-nums 내장 |
| 조 번호 | — | IBM Plex Mono ("제2조" 국문은 세리프) | 구조 정보 |

로딩 규칙: Noto Serif KR 은 선언문 굵기(600,700)만, `font-display: swap`,
`@fontsource` 자체 호스팅(R6 LCP 원칙 유지). 사용 범위: **H1·선언문·인용에만**.
본문에 세리프를 쓰면 낡아 보인다.

### 컬러 델타

없음(의도적). 오프화이트 `#FBFAF8` / 잉크 `#0E1116` / 브랜드 블루 `#3563AE` 유지.
추가 토큰 1개만: `--mt-stamp: #9E2B25`(직인 레드) — **서명란 섹션의 도장 모티프 한 곳 전용**.
액센트 3곳 이하 규칙에서 직인은 액센트로 세지 않도록 마지막 섹션에서만 등장.

## 2. 새 페이지 구조 (조항 매핑)

```
HERO      로펌 마케팅, 이제 한 곳이면 됩니다.        ← P1 선언 (세리프 오버사이즈)
제1조     문제 — 다섯 업체에 나뉜 마케팅              ← P1 (기존 수렴 인터랙션 + 질문형 카피)
          파트너 로고 (기존 유지)
제2조     계약 범위 — 별지 6개 영역 전체 품목          ← P2 (신규, ChannelGrid 대체)
제3조     변해도 조항 — 채널 레저                     ← P3 (신규, FutureReady 대체)
제4조     운영 — 발견부터 수임까지 6단계               ← P4 (기존 MarketingSystem + 선언 도입부)
제5조     성과 — 클릭이 아니라 사건                    ← 기존 LeadToCase 유지
증거      Case Study · 운영 체계 · 팀                  ← 기존 유지 (계약서 밖, 첨부서류 느낌)
Insights  기존 유지
서명란    로펌은 사건에 집중하십시오.                   ← 신규 FinalCTA (서명란 모티프)
```

### HERO (교체)

- H1(세리프, clamp 3.2→7rem): **"로펌 마케팅,\n이제 한 곳이면 됩니다."**
- 서브: 질문 리스트가 한 줄씩 등장 후 취소선 —
  "파워링크는 광고대행사에게 / Google Ads는 또 다른 업체에게 / 블로그는 블로그 대행사에게 /
  홈페이지는 제작사에게 / SEO는 SEO 업체에게" → 마지막 줄 "이제 그 모든 마케팅을
  하나의 팀에서 운영합니다." (mt-hero-in 계열, JS 없이도 전체 가시 원칙 유지)
- CTA: 마케팅 진단 요청 (기존)

### 제2조 — 계약 범위 (신규 핵심 섹션)

계약 별지 스타일. 상단: "하나의 계약으로 운영되는 마케팅" (세리프).
6개 영역을 **별지 제1호~제6호** 테이블로. 각 영역은 좌측 영역명(모노 라벨)
+ 우측 품목 전체 나열. 카피의 품목을 그대로 쓰되 상태 구분:

- 일반 품목: 기본 텍스트
- **조건부 품목은 대기 배지**: "필요 시 Meta Ads" → `조건부`,
  "법률서비스 광고 허용 시 ChatGPT Ads" → `승인 시 편입`,
  "향후 등장하는 AI 광고 플랫폼" → `등장 시 검토`
  (§42: 하는 것과 하겠다는 것을 구분해 표기하는 것 자체가 신뢰 장치)

CONVERSION 별지가 생기므로 제5조(LeadToCase)와의 중복은 이렇게 정리:
별지는 "품목"(무엇을 하는가), 제5조는 "작동 방식"(어떻게 연결되는가). 중복 아님.

### 제3조 — 변해도 조항 + 채널 레저 (신규 핵심 섹션, 다크)

강한 연출 #2 (기존 FutureReady 자리). sticky 무대:

- 고정 문장(세리프, 중앙): **"계약은 하나입니다."**
- 스크롤에 따라 위 줄이 교체: "네이버가 변해도." → "Google이 변해도." →
  "ChatGPT와 AI 검색이 새로운 고객 접점이 되어도." → 마지막: "우리가 먼저 대응하고,
  기존 시스템에 연결합니다."
- 이어서 **CHANNEL LEDGER** 표:

| 채널 | 상태 | 비고 |
|---|---|---|
| NAVER Powerlink · NAVER Ads | 운영 중 | |
| Google Ads · YouTube Ads | 운영 중 | |
| NAVER SEO · Google SEO | 운영 중 | |
| GEO · AEO (ChatGPT·Gemini·네이버 AI) | 운영 중 | |
| Meta Ads | 조건부 | 필요 시 |
| **ChatGPT Ads** | **대기** | 2026.6 한국 파일럿 시작 · 법률서비스 광고 허용 시 즉시 편입 |
| 신규 AI 광고 플랫폼 | 관찰 | 등장 시 기존 시스템에 연결 |

- 각주(작게): ChatGPT 광고 한국 파일럿 사실 출처 표기.
- 마무리 카피: "새로운 플랫폼이 등장할 때마다, 로펌이 다시 광고업체를 찾아다닐 필요가 없습니다."

### 제4조 도입부 (카피 추가)

MarketingSystem 위에 선언(세리프): **"우리가 관리하는 것은 광고가 아닙니다."**
서브: "고객이 로펌을 처음 발견하는 순간부터 … 사건을 맡기기까지. 그 전체 과정을 관리합니다."

### 서명란 (FinalCTA 교체)

- 선언(세리프 대형): "로펌은 사건에 집중하십시오.\n마케팅은 하나의 팀이 끝까지 책임집니다."
- 서명선 모티프: 좌 "위 계약의 범위를 확인하려면" + 진단 요청 버튼, 우측에 옅은 직인(--mt-stamp) 그래픽.
- 직인은 장식이므로 reduced-motion·no-JS 에서도 정적으로 안전.

## 3. 모션 예산 (§18 유지)

강한 연출 3개 상한 유지 — 목록이 바뀐다:

2. **제3조 변해도 시퀀스 (신규)** — 기존 스크롤 내러티브 인프라(mt-stage, --p) 재사용

## 5. 카피 가드레일 (§42)

- "보장" 계열 표현 금지 유지. "즉시 편입해 운영할 **계획**" — 계획임을 명시.
- ChatGPT Ads: 파일럿 사실만 진술, 법률 광고 허용 여부는 조건부로.
- Meta Ads "필요 시", 신규 플랫폼 "등장 시" — 상태 배지로 구분해 확정 서비스처럼 읽히지 않게.
- 조항 번호는 실제 계약 조항이 아니므로, 푸터 근처에 "본 페이지의 조 구성은 서비스 구조를
  설명하기 위한 편집 형식입니다" 한 줄 disclaimers 검토(법률 소비자 대상이므로).
