모든 시안의 히어로 아래에 정의·디자인 원리 5가지·시그니처·위험을 표시했다. 이 설명은 검토용 메모이며 확정된 마케팅 카피의 변경이 아니다.

### A — 디자인 원리

1. 카드 대신 큰 제목·세로 축·목차가 하나의 펼침면을 만든다.
2. 브랜드의 1을 지면의 표식으로, 여섯 업무는 하나의 목차로 편집한다.
3. 먹색과 종이색을 기본으로 붉은 편집선에 시선을 집중한다.
4. 제목은 즉시 읽히며 스크롤에는 편집선과 장식 숫자만 반응한다.
5. 모바일은 지면을 축소하지 않고 제목 아래 업무 목차를 다시 편집한다.

시그니처: 대형 헤드라인, 지면 표식으로 선 거대한 1, 여백을 가르는 붉은 편집선.

### B — 디자인 원리

1. 짙은 무대 위 중앙 선언으로 시작하고 카드 중심 문법을 버린다.
2. 여섯 업무를 수직 프레임으로 배열해 하나의 긴 시퀀스로 읽는다.
3. 따뜻한 흰색과 청회색으로 대비를 만들고 빛은 장식 선에 제한한다.
4. 스크롤에 배경 셔터만 반응한다. 제목·본문·버튼은 움직이지 않는다.
5. 영상·자동 재생·스크롤 잠금 없이 CSS와 짧은 이벤트 처리로 장면을 만든다.

시그니처: 고정된 선언 뒤에서 열리는 여섯 셔터와 화면 전체를 가로지르는 업무 시퀀스.

### C — 디자인 원리

1. 상단의 선언과 하단의 연결 도면으로 운영 구조를 먼저 보여준다.
2. 여섯 업무를 실제 서비스 페이지에 연결하고 중심에는 브랜드만 둔다.
3. 설계선·좌표·정렬을 쓰되 가짜 지표·실시간 상태를 만들지 않는다.
4. 마우스와 키보드 포커스가 같은 회선을 강조하며 JS 없이도 완성된 도면이다.
5. 모바일에서는 좌우 도면을 세로 배선으로 바꿔 읽는 순서를 유지한다.

시그니처: 여섯 서비스와 MAKETHIS1을 잇는 배선도. 서비스를 짚으면 해당 회선이 강조된다.

추천: **C**. “어떤 업무를 한 팀이 맡는가”를 가장 직접적으로 보여준다. 선택 후 사람·실제 운영 사례를 다음 섹션에 배치해 소프트웨어 제품으로 오해할 위험을 줄이는 방향이 적합하다. 아직 후속 섹션을 구현하지 않았다.

## 카피 및 사실 데이터

- 원본 히어로의 제목은 NBSP까지 유지했고, 본문·업무명·수치·CTA를 그대로 사용했다.
- 공통 카피와 서비스 링크는 기존 데이터 모듈을 직접 참조한다.
- 내부 링크는 전부 `path()`를 거친다. 서비스 버튼은 기존 상세 페이지로 연결된다.
- 가격·팀·고객·케이스를 새로 작성하거나 바꾸지 않았다.
- **카피 변경 제안: 없음.**

## 검증

기준: 별도 검증 작업트리의 production build, Windows Chrome, 1440×1000 / 375×900, 일반 / JS 비활성화 / reduced-motion.

| 검사 | 결과 |
| --- | --- |
| `npx tsc --noEmit` | 통과 |
| `npm run build` | 통과, 135개 정적 페이지 생성. 시안 3개는 SSG |
| 홈 href 추출 후 curl | 홈 24개, 비교 시안 포함 전체 28개 URL·앵커 통과. 최종 응답 모두 200 |
| `curl -A "ChatGPT-User"` | 홈·비교 허브·시안 3개, 총 5페이지 원본 HTML 확인. 대상 히어로·본문 존재 |
| canonical / 색인 정책 | 페이지별 absolute canonical 정상. 일반 robots noindex 없음. 지정 검색봇 정책 유지 |
| JS 비활성화 | 2개 해상도 × 5개 경로 확인. 본문 접근 가능. 홈의 모바일 세부 업무는 native details를 실제 클릭해 확인 |
| reduced-motion | 동일 경로·해상도 확인. 전 섹션을 스크롤해 본문 확인. 시안은 실행 도중 설정 전환도 검사 |
| 키보드 | 시안 CTA 탭 이동과 focus-visible 확인. 도면 회선 강조는 focus-within도 지원 |
| 가로 스크롤 / JS 오류 | 테스트 30회 모두 없음 |
| CLS | 시안 3개 × 2개 해상도 × 일반/감소 설정, 12회 모두 0 |
| 스크린샷 | 홈·비교 허브·시안 3개, 데스크톱·모바일의 viewport 및 full-page 저장. 시안 6개 실제 화면 검토 |

최초 빌드의 검증 환경 오류: 외부 node_modules junction을 Turbopack이 거부했다. 검증 폴더에 같은 기존 의존성을 복사한 뒤 빌드 성공. 프로젝트 의존성·설정 변경 없음.

발견·수정: 웹폰트의 지연 교체로 시안에 작은 CLS가 발생했다. 시안 경로에 한정해 설치형 폰트 스택을 사용해 제거했다. 원래 홈의 폰트는 유지된다. OS별 서체 형태 차이는 남을 수 있어 최종 콘셉트 적용 시 확인해야 한다.

본문 검사 기준: 의도적으로 숨기는 스크롤 안내는 정보 손실로 취급하지 않는다. 모바일에서는 숨겨진 데스크톱 중복 목록 대신 native details 안의 동일 본문이 열리는지 검사한다. 기존 홈의 viewport reveal은 실제로 전 페이지를 스크롤한 후 확인한다.

로컬 LCP 수치는 개발 PC·비제한 네트워크의 참고값이며 실제 이용자의 현장 성능으로 일반화하지 않는다. 히어로 제목과 버튼에는 진입 대기·페이드·무거운 애니메이션이 없다. 새 의존성, 이미지·영상 다운로드, 지속적인 애니메이션 루프는 추가하지 않았다.
