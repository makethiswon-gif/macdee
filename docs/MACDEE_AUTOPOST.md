## 흐름 (크론 한 번에 일 하나)

1. **쓰기** — 열린 칸을 `uploads`(type memo, `file_url = autopost:{키}:{날짜}:{칸}:{시도}`)로 맡고, Sonnet 5.5(high)가 JSON 원고를 쓴다. `contents`(channel google)에 비공개 `draft` 로 저장.
2. **검수·발행** — 같은 모델(medium)이 광고 규정(전문·결과 보장·최상급·무료·실제 사례)과 사실 위험(조문·기한·형량)을 고치거나 보류. 고친 뒤에도 규정 위험 표현이 남으면 기계 점검이 보류. 통과하면 gpt-image-2 표지(1536×1024 → 1200px webp)를 만들고 공개, 캐시를 비우고 IndexNow 로 Bing·네이버에 알린다.
3. 보류·실패한 칸은 새 주제로 한 번 더 쓴다(칸당 최대 2번). 보류 원고는 `contents.status = failed` 로 남아 공개되지 않는다.

글 구조: 첫 문단 결론 → `##` 질문형 소제목 4~6개(표·절차 목록) → 상담 시점 구간(변호사·사무소·지역 1회) → `## 자주 묻는 질문`(schema_markup → FAQPage) → 기준일 문장. 제목에 변호사 이름·"전문"·"|" 금지.
