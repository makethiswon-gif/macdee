# 변호사가 바로 읽는 미니멀 카피

2026-09-07 · `design/renewal-v2` · main 미병합

## 승인과 방향

대표의 후속 요청 “전체적으로 텍스트가 많으니 카피를 미니멀하게 바꾸고 변호사들이 이해하기 쉽게 수정”에 따른 변경이다. 이전의 카피 잠금보다 최신 요청을 우선했다. D 키네틱, #004AAD/화이트, ‘모든 것.’ 메인 타이포는 유지했다.

Sites 작업 기준의 쉬운 사용자 언어·불필요한 반복 제거 원칙을 적용했다. 기존 Next.js/Vercel 구조를 유지하며 호스팅을 이전하지 않는다.

## 바꾼 것

- 헤더와 푸터의 주요 메뉴를 한국어로 변경. 상담 CTA를 ‘마케팅 상담’으로 통일.
- 홈 서비스는 짧은 업무 설명이 먼저 나온다. 전체 항목은 데스크톱·모바일 모두 native details로 펼친다. 조건부 배지와 제공 조건은 남겼다.
- 의뢰인 여정의 반복 문단, 스크롤 사용 설명, 전후 비교의 중복 문장 삭제.
- 가격·포함 관계는 그대로 두고 기술 용어를 풀어 썼다. `CRO`는 ‘상담 경로 개선’, `랜딩페이지`는 ‘전용 페이지’로 표현한다.
- 홈 팀 소개는 실제 경력의 첫 부분만 보여준다. 전체 학력·이력은 회사 소개에 그대로 있다. ‘지역 MBC’의 ‘지역’ 등 사실 한정어를 보존했다.
- 매거진 홈 카드는 제목 중심으로 정리. 기사 제목·본문·데이터는 수정하지 않았다.
- 서비스 6종의 제목·정의문을 축약하고 FAQ를 native details로 전환. 모든 답변은 원본 HTML에 남고 JS 없이 펼칠 수 있다.
- 통합 업무·회사·사례·문의·진단·매거진 소개 카피도 같은 말투로 정리.

| 이전 | 변경 |
|---|---|
| 경험을 검색 자산으로 만듭니다. | 사건 경험을 글로. |
| 홈페이지를 영업사원으로 만듭니다. | 상담하기 쉬운 홈페이지. |
| 마케팅 채널 통합이 필요한 이유 | 여러 업체 대신, 한 팀이면 됩니다. |
| 세 가지 운영안과 예상 비용 | 서비스와 비용 |
| 대격변의 시대, 변화의 흐름을… | 로펌 마케팅, 지금 알아둘 것. |

## 보호한 것

- 가격의 `약`, `부터`, `광고 매체비 별도`, 상품별 전체 포함 관계와 업무 수.
- 신규 매체의 조건부 제공, AI 노출·추천 비보장, 로펌이 제공한 범위의 수임 데이터 연결.
- 실제 팀·대표·파트너·기존 실적 수치, 사례 데이터, 서비스 FAQ의 원문 조건.
- ‘법학 전공자 검수’를 ‘변호사 검수’로 바꾸지 않음. 기획·재가공을 촬영 포함으로 확대하지 않음.
- 내부 경로, canonical, named-bot 색인 정책, 루트 verification 메타 4건.
- 라이브 `/`, `/admin`, 제품, API, 고객 데이터, 매거진 slug와 발행된 기사 본문.
- D의 모션, reduced-motion 대응, 정적 LCP, `overflow-x: clip`, 무JS 본문.

‘변호사와 법무법인만 상대’는 기존 기업 고객 이력과 충돌하므로 ‘로펌 마케팅에 집중’으로 바꾸고 홈 구조화 데이터에도 맞췄다.

## 측정과 검증

`scripts/test-renewal-copy.cjs`는 `ed81b89`를 기준으로 사실·가격·조건·링크·canonical을 비교한다. 화면 문구 전체를 동일하게 강제하던 옛 카피 잠금 검사는 이번 승인된 카피 변경의 통과 기준으로 쓰지 않는다.

공백·장식·스크립트를 제외한 **본문 DOM 글자 수**는 홈 5,865 → 4,464, 서비스 허브 2,092 → 1,468이다. 접힌 설명을 포함하며, 중복 반응형 목록 제거도 반영된 수치다. 읽는 시간이나 첫 화면의 가시 글자 수 감소율을 뜻하지 않는다.

- `npx tsc --noEmit`: 통과.
- `npm run build`: 통과. 기존 middleware 명칭 경고만 존재.
- 사실·가격·조건·13개 경로 링크/canonical 비교: 통과.
- 독립 육안 검수: 375px/1440px 홈 서비스·견적·FAQ·GEO·진단 폼 잘림/가로 넘침 없음. 실제 상담 제출 없음.
- 최종 생산 빌드: 14개 경로 × 2개 너비(375/1440) × 일반·무JS·reduced-motion = 84회, 실패 0. 모든 상세를 펼친 뒤 본문 가시성과 가로 넘침 확인.
- 원본 HTML: 14개 경로 `ChatGPT-User` 요청에서 h1/본문, canonical, named-bot 정책 확인. 일반 robots noindex 없음.
- 내부 링크 82개: 모두 HTTP 200, 앵커 존재 확인.
- 초기·상세 펼침 후 스크롤 CLS: 측정된 모든 실행에서 0. LCP 장식 애니메이션 없음, reduced-motion 실행 애니메이션 0.
- 문의 모의 전송: 데스크톱·모바일 성공/선택 정보 유지, 입력 검증/오류 후 재시도/성공 포커스, 무JS 전송 방어 통과. 네트워크를 가로채 실제 문의는 보내지 않음.
- 200%에 해당하는 720 CSS px 재배치: 홈·서비스 허브·진단·문의 가로 넘침 없음.
- 시안 비교/한국어 메뉴 키보드·Escape·드롭다운 대비: 8회 통과.

구현 커밋: `767fe82` — 바쁜 변호사가 업무와 비용을 빠르게 읽도록 카피·정보 계층 개선.
