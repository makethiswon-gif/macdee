기존 리서치의 로펌명 부분 일치 프로필 덮어쓰기는 제거했다. 담당 분야를 합집합으로 넓히거나 AI 리서치 문구를 `brand_lines`에 자동 적용하지 않는다. 기존 리서치 보고서와 기존 프로필 데이터 자체는 삭제하지 않았다.

## 디자인

- 기존 journal / poster / column에 atlas / ledger / dossier를 추가했다.
- atlas는 사진 우선·하단 제목, ledger는 좌우 분할, dossier는 제목·가로 도판·설명 순서다. 체크리스트도 2열, 보고서 행, 적층 설명으로 다르다.
- 변호사 ID 기반 자동 배정을 유지하며 관리자가 지면을 직접 지정할 수 있다. 팔레트·서체·밝기와 별도로 배치가 바뀐다.
- 동일한 인물도 지면 선택을 바꿀 수 있으나, 이미 기획된 원고와 섞이지 않도록 다시 기획해야 한다.
- 글자 크기를 무작정 줄이거나 잘라내지 않고 측정한 높이에 맞춰 조판한다. 과다한 문구는 오류로 반환한다.
- 검수용 갤러리: `C:/클로드/blog-strengths-review/index.html`. 모든 인물·도판·문구는 가상 테스트 자료다. 실제 고객의 승인 사례나 AI 실생성 품질 평가가 아니다.

## 네이버 기준

네이버의 공개 설명에서 C-Rank는 출처의 신뢰도를, D.I.A.는 문서의 경험·정보성·주제 적합도 등을 함께 고려한다. 이를 바탕으로 담당 분야 일관성, 독자 질문에 대한 설명, 검증된 사실, 긴 문단 반복 경고를 적용했다. 세부 가중치·이미지 유사도 판정식·최적 발행량을 추측하거나 상위 노출을 보장하는 점수는 만들지 않았다.

- [네이버 C-Rank 공식 안내](https://help.naver.com/service/5626/contents/22927?osType=COMMONOS)
- [네이버 D.I.A. 공식 안내](https://help.naver.com/service/5626/contents/22926?osType=COMMONOS)

이미지 디자인 다양화는 브랜드 구분과 읽기 경험을 위한 것이다. 이미지가 다르면 순위가 오른다고 검증한 것은 아니다. 가상 사례는 가상이라고 밝히도록 지시하며 확인되지 않은 수임·승소 경험을 권장하던 프롬프트를 제거했다. 규칙 검사는 의미·사실·광고 적법성의 완전한 검증이 아니므로 변호사의 최종 검수가 필요하다. [대한변호사협회 광고 규칙 게시물](https://www.koreanbar.or.kr/pages/board/law_view.asp?category=3&page=1&searchstr=&searchtype=&seq=14681&teamcode=&types=6)을 참고 기준으로 확인했다.

## 저장·운영

- 별도 SQL 마이그레이션 없이 기존 **비공개** `owner-briefings` Storage 버킷을 사용한다.
- `blog-strengths/{profileId}/v00000001.json` 형식으로 승인 라이브러리 버전을 저장한다.
- `blog-strength-usage/{postId}/{digest}.json`에 사용 이력을 저장한다. 본문 변경은 다른 해시 이력으로 남는다.
- 필요한 기존 환경변수: `NEXT_PUBLIC_SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `ADMIN_TOKEN_SECRET` 및 생성용 API 키.
- 버킷이 공개 상태면 저장을 거부한다. 조회 장애를 '강점 없음'으로 감추지 않고 오류를 표시한다. 정상 조회에서 등록 강점이 없거나 관련 강점이 없으면 일반 정보형으로 생성한다.
- 승인 상태는 관리자의 확인 기록이지 AI의 자동 사실 인증이 아니다. 회사·변호사 소유 관계와 공개 근거를 먼저 확인해야 한다.
- 로펌 공통 강점도 변호사별 라이브러리에서 승인한다. 한 로펌의 문구 수정이 다른 변호사에게 일괄 전파되지는 않는다.

## 남은 운영 단계

1. 운영 배포 후 비공개 저장소 읽기·쓰기와 기존 관리자 환경변수 확인.
2. 각 변호사와 로펌의 최초 ID 연결, 공개 근거·개인 경력 귀속 확인 및 강점 승인.
3. 성격이 다른 실제 로펌 3곳의 원고·이미지를 시범 생성하여 변호사 검수. 현재 갤러리는 레이아웃·기능 검증용 가상 자료다.
4. 승인한 원고만 네이버에 게시. 게시 URL과 원고 ID를 기존 발행 기록에 남김.
5. 계획의 2~4주 관찰과 적격 상담·수임 비교는 게시 이후 진행. 이번 작업에서 네이버 클릭 추적, 자동 상담 귀속, 적격 상담 측정, 수임 성과 대시보드는 구현하지 않았다. 전화 클릭을 상담이나 매출로 간주하지 않는다.
