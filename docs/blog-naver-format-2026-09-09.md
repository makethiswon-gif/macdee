# 네이버 복사용 원고 지면 편집

2026-09-09, 로컬 구현. 푸시/배포 및 실제 네이버 에디터 붙여넣기는 미실시.

## 변경 범위

- 공유 변환기 `lib/blog-naver-html.ts`: 블로그 발행, 클로드 글쓰기, 블로그 팩토리의 네이버용 복사에 함께 적용됩니다. 저장된 원고의 사실관계와 강점 문구를 다시 쓰지 않습니다.
- 본문 17px / 행간 1.85, 제목 26px, 주요 소제목 22px, 하위 소제목 19px, 기준일/작성 14px. 문단은 왼쪽 정렬하고 모바일 너비에서 자연스럽게 줄바꿈합니다.
- 기본 여백을 0으로 명시하고 블록 사이에 빈 문단 하나만 둡니다. 일반 문단 18px, 소제목 앞 32px/뒤 12px, 이미지 전후 24px, 상담 이미지와 전화 링크 사이 12px. 연속 빈 줄은 추가 여백을 만들지 않습니다. 기존 문단 안의 명시적 개행은 유지합니다.
- 제목 단계, 번호목록 시작 번호와 불릿을 보존합니다. 본문 첫 제목이 별도 제목과 같은 경우 중복 출력만 제거합니다.
- 형광펜은 글 안에서 연노랑 한 색, 밑줄과 굵게는 원고의 표시 범위를 유지합니다. 렌더러가 임의로 키워드를 반복하거나 새 강조를 추가하지 않습니다.
- 이미지의 관련 문단 위치와 대체 텍스트를 보존하고 여러 줄 문단도 위치를 찾습니다. 상담 이미지는 대표번호 링크 위, 기준일/작성 정보는 아래에 둡니다. 이미지가 없어도 텍스트 복사가 됩니다.
- HTTP(S) 이미지, 검증한 전화 링크만 허용하고 원고/이미지 속성은 이스케이프합니다. 이미지 URL의 사용자명/비밀번호는 허용하지 않습니다.
- 블로그 발행 화면의 `원고 편집` / `서식 미리보기` 탭. 미리보기와 실제 클립보드는 같은 변환 함수와 이미지 위치 데이터를 사용합니다. 미리보기는 스크립트와 탐색을 허용하지 않는 sandbox iframe입니다. 편집 시 이전 이미지가 함께 초기화됩니다.
- 생성 및 윤문 지침: 문단은 한 논점, 소제목 첫 문단에서 답 제시, 강제 개행/연속 빈 줄/중첩 강조 금지, 모바일용 목록과 비교 문단, 확인된 강점과 전화 링크 보존. 변호사별 문체/이미지 디자인 설정은 유지합니다.

## 검색 관련 기준

## 남은 확인

네이버 스마트에디터는 외부 HTML의 제목, 빈 문단, 글꼴, 이미지 등을 자체 형식으로 바꿀 수 있습니다. 로컬 contenteditable 시험은 실제 네이버 에디터 시험을 대신하지 않습니다. 배포 후 발행하지 않는 임시 글에서 PC/모바일 간격, 강조, 이미지 업로드 및 대표번호 링크 유지 여부를 확인해야 합니다. 검색 노출/상담 전환 효과는 실제 게시 후 별도 측정 대상입니다.

## 전화 링크 표시 보완

- 스크린샷과 같은 저장 원고를 운영 사이트의 블로그 공장에서 새로 열어 네이버용 복사를 실행했습니다. 실제 시스템 클립보드 HTML에 올바른 전화 링크가 있으며, HTML/일반 텍스트 모두 전화 마크다운이 없음을 확인했습니다. 당시 화면의 원인은 캐시/복사 경로/붙여넣는 편집기 중 어느 것인지 아직 확정되지 않았습니다.
- 별도로 블로그 발행 화면에서 `text/plain`에 마크다운 원문을 싣던 경로를 발견했습니다. 대체 데이터도 렌더링한 HTML에서 읽을 수 있는 본문 텍스트로 추출하도록 변경했습니다. 일반 텍스트 붙여넣기는 링크 기능을 보장하지 않지만, 적어도 `[문구](tel:번호)` 원문이 노출되지 않습니다.
- 클로드 글쓰기/블로그 공장의 네이버용 복사도 동일한 공유 함수로 통일했습니다. HTML 우선 복사, 권한 실패 시 선택 복사, 기존 선택 영역 복원, 모든 복사 경로 거절 시 실패 표시를 함께 적용합니다.
- `scripts/test-blog-clipboard.cjs`: 신고된 전화번호의 HTML 링크 대상, 실제 DOM 클릭 이벤트(통화는 차단), 일반 텍스트 결과, 현대/구형 API 성공·실패, 선택 영역/임시 DOM 정리를 검증합니다. 실제 네이버 붙여넣기나 발행 검증은 아닙니다.
