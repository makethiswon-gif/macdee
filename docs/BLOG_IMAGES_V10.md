# Blog Images V10 — 변호사별 지면 정체성 + 레이아웃 리듬

작업일 2026-09-07. V9(매거진 스튜디오) 위에 얹는 개편이다. 기획·이미지·검수
파이프라인과 AI 호출 구조는 그대로 두고, **누가 지면을 소유하는가**와
**렌더러의 리듬 규칙**만 바꿨다.

## 1. 변호사별 정체성 (`lib/blog-images/magazine-identity.ts`)

V9 는 팔레트·서체를 기획 모델이 글마다 골라 8개 블로그가 같은 스튜디오
출력물로 보였다. V10 원칙:

> "무엇이 다른가"는 변호사가, "무엇을 그리나"는 원고가 정한다.

- 변호사 고정: **팔레트(5) · 서체 계열(serif/sans) · 지면 스타일(paper/contrast)** = 20조합
- 원고별 자유: 콘셉트·모티프·구도·장면 (기획 모델 몫 그대로)

팔레트는 브랜드 컬러의 hue 로 맵핑(로고와 조화·결정론). **무채색(#080808 등)은
"색 정보 없음"으로 보고 해시 분산** — 실측에서 등록 15명 대부분이 로고 추출
검정이라, graphite 수렴을 막는 것이 핵심이었다 (4조합 → 9조합).

겹침 조정: `blog_profiles.dna_salt` 가 정체성 해시에 들어간다.
두 변호사 지면이 겹치면 `/admin/blog-settings` 의 DNA 조정칸에 아무 글자나
넣어 갈라낸다. 같은 사람은 언제나 같은 지면(결정론 유지).

배선: `/plan`·`generate-design` 요청에 profile 동봉 → `identityDirective` 가
기획 프롬프트에 시리즈 규정 주입 → 응답이 무엇이든 `lockDirection` 이
변호사 값으로 덮어쓴다(공유·저장·구버전 플랜 전부). style 미지정 시
기본값도 "contrast" 고정이 아니라 변호사 축.

## 2. 렌더러 리듬 (`magazine-design.ts` · `magazine-renderer.ts`)

- **표제 크기 규칙**: 행이 많을수록 작게(3행 ≤76px, 4행 ≤60px). 3행 표제가
  최대 크기로 지면을 꽉 채우던 문제의 근본 해결 — 큰 표제는 1~2행의 특권.
- **정보 카드**: 목록을 여는 3px 선과 같은 무게로 닫는 선 추가 + 하단 트레일
  72→44. 마지막 항목 뒤 여백이 "남은 공간"으로 읽히던 문제 제거.
- **연락 카드**: 이름 블록을 초상 세로 중앙 정렬(좌측 400px 공백 해소).
  액센트는 초상 프레임 한 곳만 — 제목 밑줄은 muted 로.
- **분할형 표지**: 설명 상자의 측정 폭(I-64)과 그리기 폭(I-120)이 달라
  글자가 상자 밖으로 잘리던 버그 수정. 같은 폭 + 여유 52px + 좌측 액센트 바.
- **마스트헤드**: 킥커가 좌측 라벨과 같으면 생략(같은 글자 2회 방지).

## 3. QA 갤러리 (`scripts/blog-images-gallery.mts`)

AI 호출 0회 레이아웃 검증. 픽스처 플랜 + 대체 시각물로
[변호사 3명 × 카드 4종] PNG 와 gallery.html 을 뽑는다.

```
npx tsx scripts/blog-images-gallery.mts [출력폴더]
```

렌더러를 고치면 반드시 이걸 돌려 눈으로 확인한다. 12장 렌더·경고 0·잘림 0 확인됨.

## 4. 미검증 (다음 확인 항목)

- 실제 AI 전체 파이프라인(기획→생성→검수→렌더)에서 잠긴 팔레트로 그림이
  조화롭게 나오는지 — 관리화면에서 실물 1세트 생성으로 확인 필요.
- 활동 변호사 간 남은 겹침은 dna_salt 로 수동 분리 (위 §1).
