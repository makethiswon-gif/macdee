# 기존 고객 통합 상품 전환 안내

2026-09-07 · `design/renewal-v2` · main 미병합

## 최신 후속 승인 — GROWTH 월 500만원

대표 요청으로 GROWTH를 **월 500만원**으로 변경했다. STANDARD 전체 및 기존 GROWTH 업무를 유지하면서 **유튜브 월 총 20회 발행(쇼츠 12회 포함), 촬영·편집 포함**을 추가한다. 20회에 쇼츠 12회를 별도로 더하는 것이 아니다. 나머지 영상의 형식·길이, 촬영 횟수·일정·장소 등 미확정 세부조건은 임의로 약속하지 않았다. 광고 매체비 별도·부가세 확인 대기 조건과 MARKET LEADER의 가격/상속 관계는 유지한다.

홈 가격표·공통 가격 안내·상담 선택과 접수 메모·기존 고객 안내의 GROWTH 소개 및 FAQ에 반영했다. STANDARD의 별도 촬영 제외 조건과 GROWTH의 유튜브 촬영·편집 포함을 구분한다. 이하 GROWTH 600~700만원 및 상위 상품 불변 기록은 이전 시점 기록이며 이번 승인이 우선한다.

GROWTH 검증: 타입 검사·빌드 통과. 홈/안내/상담 × PC/모바일 × 일반/no-JS/reduced 18개 조합, 원본 HTML 15개와 내부 링크·앵커 85개 통과. CLS 0, 가로 넘침·숨겨진 본문·reduced 실행 애니메이션 없음. 기존 폼 4가지 회귀와 STANDARD/GROWTH 선택·가격 메모 모의 제출을 두 화면 크기에서 확인했다. 증거: `C:/클로드/renewal-upgrade-qa/growth-500/`. 실제 문의·촬영 예약·고객 요금 변경은 하지 않았다.

## 후속 반영 — 상담·사례 공유와 SNS 활동

대표 요청으로 상담 내역·승소사례를 로펌이 직접 간단히 올리고 광고 전략에 반영하는 업무를 기본 상품에 명시했다. 월 1회 모아 입력 가능, 별도 보고서 불필요, 핵심만 적거나 붙여넣는 방식이다. 기존 `/portal`의 유형·제목·내용 입력 및 로펌별 자료 조회 코드를 읽어 확인했으며, 자료함 자체나 고객 계정·DB는 변경하지 않았다. 실제 고객 자료 업로드는 테스트하지 않았다.

안내의 블로그 재활용 예시 섹션을 **로펌 입력 → 담당팀 분석 → 검색어·예산·콘텐츠 전략 반영** 흐름으로 교체했다. 개인정보는 입력 전에 제외하고, 공유 자료의 공개 콘텐츠 활용은 로펌과 먼저 확인한다. 완전 자동 익명화·보안 인증·파일 일괄 업로드는 약속하지 않는다.

SNS는 블로그 재가공에 한정하지 않는다. 로펌 소식·법률 이슈·채널별 콘텐츠 기획·프로필 정비 등 필요한 활동을 협의한다. 댓글·메시지 대응은 별도 범위 협의이며 법률 상담 대행을 뜻하지 않는다. 발행량·촬영 관련 미확정 조건은 유지했다. 서비스 허브에서도 현재 자료 공유와 미제공 통합 대시보드 확장을 구분했다.

후속 검증: 타입 검사·프로덕션 빌드 통과. 변경된 홈/안내/서비스 허브 × 1440/375 × 일반/no-JS/reduced 18개 조합, 15개 원본 HTML 및 내부 링크·앵커 85개 통과. 기존 폼 4가지 시나리오와 전환 동선 PC/모바일 모의 검증 통과. 실제 자료 업로드·문의 전송 없음. 증거는 `C:/클로드/renewal-upgrade-qa/records-sns/`에 저장했다. 아래 90개 조합은 최초 상품 안내 작성 당시 전체 회귀 검증 기록이다.

## 승인한 변경

대표 요청: 블로그 관리 중심의 기존 고객을 **월 250만원 통합 운영 상품**으로 전환한다. 블로그 월 20회, SEO·GEO, 홈페이지 연결, 키워드 광고·퍼포먼스 마케팅, 상담 분석, 쓰레드·인스타그램 연계 운영을 포함한다. 유용한 추가 업무 선정도 요청받았다.

- 홈의 세 상품 중 STANDARD만 `약 월 300만원 / 기본 운영`에서 `월 250만원 / 통합 운영`으로 변경.
- GROWTH `약 월 600~700만원`, MARKET LEADER `월 1,300만원부터` 그대로. `STANDARD 전체 + / GROWTH 전체 +` 관계 유지.
- 새 `/renewal/upgrade`: 포함 업무 → 콘텐츠 활용 → 비용 → 전환 순서 → FAQ → 상담.
- 홈 가격표 아래와 푸터에 전환 안내 링크. 상담 폼은 STANDARD를 선택하고, 기존 API가 저장하는 `note`에 선택 상품과 사용자의 원문 메모를 함께 전달한다. API·DB는 변경하지 않는다.
- 블로그 서비스 FAQ의 ‘발행 건수를 먼저 정하지 않는다’는 문장을 월 20회 기준으로 정합화.

## 추가한 관리 업무와 판단

플레이스의 기본정보 점검, 상담 버튼·링크 점검, 월간 성과 요약과 다음 달 계획을 포함했다. 새 촬영·제작량을 늘리기보다 이미 운영하는 콘텐츠와 상담 경로를 유지관리하는 구성이다. 리뷰 대응은 사건정보·응대 승인 부담이 있어 이번 기본 상품에 넣지 않았다.

참고한 공식 자료: [네이버 플레이스 정보 변경](https://help.naver.com/alias/NSP_M/NSPM_13.naver), [서치어드바이저 콘텐츠 가이드](https://searchadvisor.naver.com/guide/content-basic). 추가 업무의 제공 약속은 플랫폼의 성과 보장이 아니라 담당팀의 점검 업무다.

## 비용·제공 조건

- 광고 매체비: 기존 별도 정책 유지. 네이버·구글에 집행하는 예산은 사전 협의.
- **부가세 포함 여부: 대표 확인 대기.** 화면은 ‘최종 견적서에서 확인’으로 표시. 고객 배포 전에 확정 권장.
- 월 20회는 블로그 기준. SNS별 수량·채널 운영 범위는 사전 합의. SNS마다 20회라는 약속은 하지 않는다.
- 홈페이지는 기존 사이트의 콘텐츠·상담 경로 연결. 신규 제작·대규모 개편·별도 촬영·영상 신규 제작은 기본 포함으로 표시하지 않는다.
- 기존 고객 모두가 이미 월 20회를 이용했다고 가정하지 않는다. 현재 발행량 확인 후 전환.
- 시작일·계약기간·검수 방식은 서면 협의. 이 안내만으로 기존 요금·계약이 바뀌지 않는다.
- 검색 순위·AI 추천·상담 수 비보장. 분석은 확인 가능한 유입과 제공된 데이터 범위.

## 디자인·기술

Sites 작업 원칙의 짧은 사용자 언어와 정보 위계를 적용했다. 기존 Next.js/Vercel 구조와 D 키네틱 `#004AAD`/화이트를 유지한다. 큰 `250` 견적서와 `20` 발행량을 중심으로 구성하고, 6개 선이 스크롤에 따라 모이는 장식만 움직인다. 본문·가격·CTA는 SSR 정적 콘텐츠다.

- JS 없이 모든 섹션·FAQ를 읽을 수 있다. FAQ는 native details.
- reduced-motion: 장식 정지, 리뉴얼 범위의 실제 스크롤 요소 `html`에도 `scroll-behavior:auto` 적용.
- `path()` 내부 링크, 페이지별 absolute canonical, 검색봇 정책 유지.
- 라이브 홈·관리자·API·결제·고객 데이터·실제 사례·매거진 slug·verification 메타·의존성 변경 없음.
