## 바꾸지 않은 것과 이유

- 확정 히어로/본문/가격/팀 이력/파트너/케이스: 대표 확정 사항이며 디자인 작업이므로 유지.
- `data/renewal/*.ts`, root verification 메타 4건, flags 색인 정책, 페이지 canonical, 매거진 slug: 사실·SEO 불변 조건.
- 내부 링크 및 문의 payload/endpoint: 기존 이동과 업무 흐름 유지. 새 마케팅 경로를 하드코딩하지 않았다.
- 라이브 `/`, `/admin`, 맥디 제품/API, 의뢰 데이터: 이번 범위가 아니다.
- 의존성/lockfile: 변경 없음. 기존 CSS/SVG/React만 사용했다.
- A/B/C/E/F 시안은 비교용으로 남겼다. D만 선택 팔레트를 반영했다.
