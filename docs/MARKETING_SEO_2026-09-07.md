# 메이크디스원 공개 홈페이지 검색 최적화 — 2026-09-07

## 기준과 실측

대표 요청: 법무법인 마케팅 등으로 Google에서 메이크디스원을 발견할 수 있도록 홈페이지와 기존 매거진을 최적화한다.

Google Search Console의 `https://www.makethis1.com/` 속성을 로그인된 브라우저에서 확인했다. 2026-06-06~2026-09-05 웹 검색 기준 전체 833클릭·18,748노출. 고객 변호사 블로그도 포함된 수치다. 검색어에 `마케팅` 포함 필터는 0클릭·10노출(변호사 마케팅 비용 8, 변호사 마케팅 1, ai 마케팅 트렌드 1). 필터 보고서는 일부 익명 검색어가 생략될 수 있으므로 전체 사업 수요나 정확한 시장 검색량으로 해석하지 않는다.

기존 사이트맵은 Google에서 2026-09-07 읽기 성공, 발견된 페이지 1,121개. 매거진 발행글은 91편인데 목록은 최신 60편만 반환하고 `?page=2`도 같은 본문·첫 페이지 canonical·noindex였다. 따라서 31편은 목록으로 찾을 수 없었지만 사이트맵에는 이미 존재했다. 별도로 공개 고객 블로그 쿼리는 실제 2,285건이지만 Supabase 기본 반환 제한 때문에 사이트맵에는 일부만 실렸다.

## 적용

- 홈 title을 `법무법인 마케팅 · 변호사 광고 | 메이크디스원 MAKETHIS1`로 변경하고 설명·히어로 보조 문장에 대상과 업무를 명시했다. 기존 키네틱 H1과 디자인 유지.
- 홈 비용 제목을 `변호사 마케팅 비용과 서비스`로 변경. 승인 가격·상품 구성·사례·팀 데이터는 변경하지 않았다.
- 서비스 허브와 6개 상세에서 주제에 맞는 제목/서비스명/설명 및 `Service` 구조화 데이터를 제공한다. 내부 경로와 canonical은 기존 `path()/absUrl()` 정책을 따른다.
- 매거진 전체를 18편씩 SSR 페이지네이션. 카테고리도 실제 링크이며 각 유효 목록이 자기 canonical을 갖는다. 없는 페이지·카테고리는 404. 추적용 query는 canonical에서 제외.
- 기존 글의 제목·태그·요약으로 서비스 관련성을 계산한다. 홈/서비스에서 관련 글로, 글에서 관련 서비스로 연결한다. 무관한 글로 채우지 않는다. 원문·slug·DB 데이터는 그대로다.
- 홈/허브 추천은 원문을 검토한 기존 3편(125402348 로펌 마케팅 시작, 26243995 블로그와 상담, 13069827 전환율)을 우선한다. 해당 글이 비공개가 되면 노출하지 않는다.
- 편집팀은 `Organization`, 개인 작성자는 `Person`으로 표현. Article JSON-LD의 `<` 이스케이프와 OG 기본값을 보완.
- 매거진 `updated_at`은 조회수 변경으로 갱신되므로 콘텐츠 수정일로 사용하지 않는다. 실제 발행일만 표시·피드에 반영하고 정적 페이지의 임의 lastmod는 제거.
- 사이트맵은 모든 공개 행을 배치 조회하고 공식 도메인·중복 제거·XML 이스케이프 적용. DB 오류 때 부분 사이트맵을 성공 응답하지 않는다.
- RSS의 브랜드·주소·실제 발행일·CDATA 보완. llms.txt에 발행 매거진 링크 추가. 이 파일 자체가 Google 순위를 높인다고 주장하지 않는다.
- 관리자·포털·제품·인증·결제·고객 데이터·4개 검색엔진 소유권 인증 태그는 변경하지 않았다.

## 검증과 배포

- `npx tsc --noEmit`, 변경 파일 ESLint, `npm run build`.
- `node scripts/test-seo-feeds.cjs`: DB 응답 제한을 넘는 전체 수집, 날짜, XML, 실패 응답.
- 로컬 서버와 테스트 프로세스 모두 `RENEWAL_QA_READ_ONLY=1`. 실제 문의 전송/비밀번호/고객 자료 쓰기는 하지 않는다.
- `node scripts/test-marketing-seo.cjs http://localhost:3106`: 주요 14경로, canonical/robots/SSR/JSON-LD, 4개 인증, 사이트맵, 페이지네이션, 기사 표본.
- `node scripts/test-marketing-seo-ui.cjs http://localhost:3106`: 전체 매거진 탐색과 375/1440px·JS 비활성·reduced-motion. 증거는 `.next/seo-qa`.
- 실서버 HTTP 검사에서는 기사 GET을 생략하여 조회수를 인위적으로 올리지 않는다.
- 검증 통과 후 GitHub main push → Vercel 자동 배포, Google Search Console 사이트맵 재제출 및 주요 URL 색인 요청.
