# V8 — 인물 중심 상담 안내

2026-09-06. 사용자의 “더 감각적인 법률 콘텐츠 디자인” 피드백과 “마지막 이미지에 변호사 사진과 contact” 요청의 후속 작업이다. 이번 실제 레이아웃 교체는 마지막 상담 안내 장을 중심으로 했다. 표지·본문 정보 그래픽의 V7 레이아웃 전체가 교체됐다는 의미는 아니다.

## 마지막 장

- 기존 요약 + 작은 프로필 띠를 별도의 인물 중심 상담 레이아웃으로 교체했다.
- 원고에서 이어지는 상담 질문, 확인할 쟁점, 크게 보이는 실제 변호사 사진·이름, 독립된 연락처 영역을 사용한다.
- 등록 사진은 비율을 보존해서 배치한다. 얼굴·몸·직함을 AI로 만들거나 실제 인물을 다시 그리지 않는다. 로고도 등록 자산을 그대로 사용한다.
- 전화번호와 홈페이지는 등록값만 표시한다. 사진과 유효한 연락처가 없거나 사진을 읽지 못하면 상담 카드를 완성 처리하지 않는다.
- 상담 카드가 원고 기획에서 생략되지 않도록 변경했다. 무료 상담·즉시 답변·직접 응대·승소 보장·미등록 경력 등을 약속하지 않도록 기획 지침을 추가했다.
- 레거시 프로필 조회 시 직함이 없다고 `대표변호사`를 임의로 보충하던 부분을 제거했다. DB 저장값 자체를 변경하지 않았다.

## 실제 상담 연결

PNG는 전화 버튼이나 웹 링크가 아니다. 완성 이미지 아래의 관리자 UI에서 전화/홈페이지 링크를 따로 복사할 수 있고 ZIP의 삽입 안내에도 실제 URI를 포함한다. 네이버 본문에서 이미지 아래에 링크를 넣어야 한다. 이번 변경은 네이버 게시물에 링크를 자동 삽입하거나 게시하는 기능이 아니다.

`사진·연락처 새로 반영`은 최신 등록 프로필을 다시 읽어 상담 카드 한 장만 합성한다. 다른 유료 AI 시각물을 재생성하거나 원고를 재기획하지 않는다. 미등록 사진을 추가한 뒤 실패한 상담 카드만 다시 시도하는 경우에도 같은 방식으로 최신 프로필을 읽는다.

## 앞선 디자인 피드백 반영 범위

AI 시각물 기획에서 베이지·찢어진 종이·문서 뭉치를 모든 원고에 반복하는 기본 스타일 지시를 제거했다. 원고가 설명하는 관계를 중심으로 스튜디오 정물, 정밀한 선화, 절제된 개념 오브젝트 등을 선택하게 했다. 원고가 서류 자체를 설명할 때 서류를 금지하는 식의 무리한 제약은 두지 않았다.

이 지침의 기획 응답은 실제 텍스트 모델로 확인했지만, 변경 지침으로 새 AI 시각물 전체를 생성·평가한 것은 아니다. 표지/본문의 전면 아트디렉션은 후속 시안 검토 범위로 남아 있다. 편집 디자인 참고 자료: https://www.pentagram.com/work/coqual/story

## 검증 및 출력

- 기존 렌더러/인증/근거/PNG·ZIP 회귀 테스트 유지.
- 사진 누락, 연락처 누락, 위험한 URI, 연락처 링크 생성 검증.
- 그림의 텍스트 경계·겹침과 응답 크기 검사.
- 데스크톱/390px/360px 관리자 UI에서 링크 복사, ZIP 링크 포함, 최신 프로필로 상담 카드만 갱신하는 흐름 검증.
- 실제 등록 프로필 1개의 사진·로고·연락처로 합성 결과를 직접 확인. 프로필은 읽기만 했고 DB/게시물은 변경하지 않았다. 예시 문구는 기능 검수용 원고이며 해당 변호사의 실제 게시 원고가 아니다.
- TypeScript 검사, 변경 핵심 파일 ESLint, 프로덕션 빌드 및 변경 파일의 diff 공백 검사 통과. 기존 Next.js middleware 명칭 경고는 남아 있다.
