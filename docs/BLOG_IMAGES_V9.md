# Blog Magazine Studio V9

작업일: 2026-09-06~07. 로컬 구현/QA 완료 후 인수인계. 개발 단계에서는 배포·커밋·푸시를 하지 않았다. 2026-09-07 사용자 요청으로 기존 Vercel 운영 배포를 진행한다. 고객 원고 발행·DB 변경은 포함하지 않는다.

## 무엇이 바뀌었나

- V7/V8의 고정 헤더 + 사진 패널을 새 매거진 렌더러로 교체했다. 표지는 풀블리드 또는 밝은 갤러리 지면, 본문 삽화는 별도 편집 플레이트, 정보는 데이터 중심 지면, 마지막 장은 실물 변호사 프로필과 연락처다.
- 원고 전체를 읽고 채택 가능한 콘셉트 3개를 비교한다. 선택 이유, 다른 대안, 팔레트 5종, 명조/고딕, 구도, 시각 모티프, 제목 행갈이를 구조화한다. 표지의 주인공과 글자 안전영역까지 이미지 프롬프트에 전달한다.
- 인쇄되는 한글/수치/연락처는 생성 그림과 분리해 로컬 서체로 정확히 합성한다. 제목·설명·목록은 측정한 폭으로 균형 있게 줄바꿈하며 글자를 잘라 저장하지 않는다. 명조 700 / 고딕 900 / 본문 400 폰트를 서버 배포 추적에도 추가했다.
- 본문용 이미지에 세로 표지 구도를 재사용해 중요한 대상이 잘리던 경로를 분리했다. 표지 1024×1280, 본문 아트 1536×1024 생성. 최종 PNG는 폭 1024, 내용에 따라 높이 가변, 불투명, 2MB 이하로 제한한다.
- 등록 변호사 사진은 비율을 유지해 전체를 배치한다. 얼굴/인물/직함/로고/연락처를 생성하지 않는다. 긴 상담 설명은 사진 옆 좁은 열 대신 전폭으로, 확인 항목은 두 열로 배치한다. PNG 자체는 클릭할 수 없으므로 실제 상담 URI 복사/ZIP 안내 기능을 유지한다.

## 모델 선택

| 역할 | 실제 기본 모델 | 설정 |
| --- | --- | --- |
| 원고·카피·아트디렉션 | `claude-fable-5-1` | adaptive thinking, high effort, 최대 출력 18,000토큰 |
| 시각물 생성 | `gpt-image-2` | 기본 high, opaque PNG, 명시적 1회 호출 |
| 생성 그림의 원고 적합성 | `claude-opus-5` | 비전, 최대 2,200토큰 |
| 완성 PNG 독립 검수 | `gpt-6-astra` | 비전, medium reasoning, strict JSON schema, 최대 4,200토큰, store:false |

OpenAI/Anthropic/Google의 등록 계정 모델 목록을 읽기 전용으로 확인했다. Fable 5.1, Opus 5, GPT Image 2, GPT-6 Astra는 실제 API 호출까지 확인했다. Google 모델 전체와의 이미지 품질 벤치마크를 수행한 것은 아니다.

초기 Opus 5 기획은 일부 원고를 추상 격자·금속으로 치환했다. Fable 5.1과 더 구체적인 주제 단서를 요구하는 기획 지침으로 변경한 뒤 보증금 원고에서 이사 공간·상자·입금 자료로 연결되는 콘셉트가 나왔다. 모델과 프롬프트가 함께 바뀐 실용 비교이며, 통제된 모델 성능 실험이나 모든 모델 중 절대적인 최적 성능의 증명은 아니다.

OpenAI Docs 스킬과 공식 문서 확인이 모델 ID, 유효 해상도, high 품질, Responses 비전·구조화 출력 선택에 반영됐다. 모델이 바뀌면 위 상수를 명시적으로 검토한다. 실패했다고 임의의 다른 모델이나 저품질로 조용히 전환하지 않는다.

## 비용·검수·안전

- 기본 3장: 기획 1회 + 이미지 1회 + 이미지 적합성 검수 1회 + 완성본 검수 최대 3회. 보조 시각물은 생성/적합성/완성본 각 1회 추가. 정확한 과금은 계정 청구 내역으로 확인한다. 토큰·이미지 품질을 높였으므로 이전 구성보다 비용·대기 시간이 늘어난다.
- 실제 원문 인용/문단 ID/source hash 검증을 유지한다. 없는 법적 조건·결론·성과·자격은 만들지 않도록 지시하고, AI 검수가 법률 정확성이나 광고 적법성을 보장한다고 표시하지 않는다.
- 완성본 검수는 카드별 역할을 본다. 설명 그래픽과 연락처 장에 표지의 사진/메타포를 반복하라고 요구하지 않는다. 그림의 사소한 앞뒤 방향 차이를 실제 사건 증거 위조와 혼동하지 않도록 분리했다.
- `pass`도 AI의 보조 판단이다. 점수는 내부 보조값이며 UI는 점수 보장 대신 구체적인 검수 메모를 보여준다. 소품이 통장보다 수첩처럼 보이는 등, 생성 모델의 미세한 식별성 한계는 남을 수 있다.
- 적합성 보류 그림도 원본 아트와 PNG를 보존한다. 자동 재생성/중복 결제 요청 없음. 완성본 검수 장애 시에도 이미지는 보존하고 직접 검수 필요 상태를 보여준다.
- 제목/레이아웃 변경은 같은 원고의 캐시 아트를 사용해 AI 호출 없이 렌더링한다. 이전 보류 메모를 단순 편집으로 지우지 않는다. 편집 후 새 AI 검수를 실행했다고 주장하지 않는다.
- `blog-publish`와 `blog-factory`는 보류/검수 불가 결과를 자동 이미지 저장 경로로 넘기지 않고 관리자 확인을 요청한다. 수동 이미지 스튜디오에서는 경고를 확인하고 직접 저장할 수 있다.
- 변호사 프로필 1건은 명시적 테스트 옵션으로 읽기만 했다. 고객 사건 원고는 모델 테스트에 사용하지 않았고, 가상 원고만 사용했다. 키/토큰은 로그나 결과물에 기록하지 않았다.
