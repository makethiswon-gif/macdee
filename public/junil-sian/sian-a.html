법률사무소 준일

상담수행 변호사가 직접 상담 · 모든 변호사가 논의·검토수행
CORE VALUE 01전문성

준일은 음주운전, 마약, 사이버모욕·명예훼손, 부동산 재건축·재개발 전문 대형·부띠끄 로펌 출신 변호사들의 풍부한 실전 경험과 전문성을 바탕으로 최적의 법률서비스를 제공합니다.

CORE VALUE 02협업

준일은 각 분야에서 전문성을 갖춘 변호사들이 초기 상담단계부터 재판단계까지 모든 절차를 협업하여 복잡한 법률 사안에 있어 의뢰인을 위한 구체적이고도 현실적인 해결책을 제시합니다.

CORE VALUE 03신뢰

준일은 소통 중심의 사건 처리 방식을 지향하며 의뢰인의 사소한 고민 역시 파악하고 정직한 소통으로 신뢰 관계를 구축하여 최선의 결과를 도출합니다.

CORE VALUE 04결과

준일은 결과 중심 회사로 언제나 철저한 사전 분석과 전략적 대응으로 의뢰인에게 최선의 결과를 이끌어냅니다.
