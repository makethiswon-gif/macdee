# Face detection model

`haarcascade_frontalface_default.xml` is the unmodified frontal-face cascade
from OpenCV 4.12.0:
https://github.com/opencv/opencv/blob/4.12.0/data/haarcascades/haarcascade_frontalface_default.xml

The Intel/OpenCV license notice is retained inside the XML. Detection runs
locally in the server's OpenCV.js runtime; no photograph is sent to a detection
service. This is face-location detection, not facial identity recognition.
